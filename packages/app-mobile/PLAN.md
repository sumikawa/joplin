# Android DeX PC風レイアウト

## 目標

Samsung DeXのデスクトップディスプレイで、PC版に近い「ノートブック」「ノート一覧」「Markdown本文」「プレビュー」の4領域を表示する。DeX以外では現在のモバイル画面と編集動作を保つ。

## レイアウトと切替

- SamsungのDeX設定値、Samsung端末のデスクトップUIモード、またはSamsung端末の外部ディスプレイ上のActivityを確認し、DeX表示を有効にする。画面構成の変化やアプリ復帰時に再判定する。
- 現在のウィンドウ幅が850dp以上なら、サイドバー、ノート一覧、Markdown本文、プレビューを横並びにする。1100dp未満ではサイドバーとノート一覧を縮め、850dp未満ではモバイル表示に戻す。
- 外部画面のリサイズ後にReact Nativeの画面幅が更新されない場合があるため、幅は現在のActivityから取得する。レイアウト切替時もノート画面のReactツリーを維持し、保存処理と再読み込みの競合を避ける。
- ノートの選択IDは既存のRedux状態を使う。編集中は既存の本文変更処理からプレビューを更新し、DeX表示を終えたらモバイルの表示設定に戻す。
- Activityの密度・ナビゲーション・画面サイズ・`uiMode`変更を受け取り、リサイズやDeX切替の後も選択と編集状態を維持する。
- AndroidのJavaScriptバンドル作成タスクは、リポジトリのルートで`yarn tsc`を先に実行し、Metroが読む生成済み`.js`を更新する。
